# LiveMediaClipsMp4SupportType

The MP4 rendition type. `capped_4k` is a downloadable MP4 video capped at 4K resolution, `audioOnly` is a downloadable m4a audio-only file.


## Values

| Name       | Value       |
|------------|-------------|
| CAPPED4K   | `capped_4k` |
| AUDIO_ONLY | `audioOnly` |
